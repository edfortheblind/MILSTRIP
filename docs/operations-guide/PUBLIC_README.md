# MILSTRIP field guide

A practical guide to the current development app and its proposed production path.

**[Open the latest release](https://github.com/edfortheblind/milstrip-guide/releases/latest)**

1. Download **index.html** from the release assets.
2. Open the downloaded file in your browser. Everything needed to read it is embedded.
3. Start with the six-step SOP. Expand recovery instructions or diagrams when needed.

No account or login is needed to read the files. The HTML works offline.
Use **View larger** for full-size diagrams, **Escape** to close, and **Print guide**
for an expanded paper copy. A two-page quick SOP and a full illustrated PDF are
also available. The ZIP includes both PDFs, HTML and seven standalone SVGs.
SHA256SUMS.txt contains checksums for the downloadable files.

## What is current?

Evidence date: **September 23, 2026**. The Power App is an **unpublished development
draft** with intake, review and history. Approval does not send or ship an order.
Phase 2 proposes existing Azure SQL first, then accepted production PostgreSQL,
targeting the end of Q4 2026.

This repository publishes documentation only. Downloading the guide does not
publish, install or grant access to the Power App. Source code, credentials,
private engineering notes and business records are not part of this release.
